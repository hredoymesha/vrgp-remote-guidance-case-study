# VRGP Remote Guidance Case Study

This is a public portfolio case study based on a university project where I worked as the Project Manager for a Vessel Remote Guidance Protocol implementation concept.

## Project Purpose

The project explored how a vessel could communicate with an onshore maritime operations center to support remote guidance, monitoring, and docking decisions.

This repository presents a public-safe version of the project as a simple one-page website.
